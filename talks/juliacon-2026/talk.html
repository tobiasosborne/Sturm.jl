Julia is uniquely placed to be a quantum programming language — I won't argue it abstractly. Watch for six levers.

① The compiler is a library

ir_string = sprint(io -> code_llvm(io, f, arg_types;
                       debuginfo = :none, optimize, dump_module = true))
mod = parse(LLVM.Module, ir_string)

A runtime function value in — the compiler's IR out. In-process. While f is still callable.

C++: write a clang plugin. Python: there is no IR. Julia: two lines, and it works for anything that reaches LLVM.

Julia 1.12 outlines slow paths — some closures have no .instance to compile. Fix: rebuild InteractiveUtils._dump_function from Base._which + specialize_method + typeinf_code. The reflection stack is just more Julia you can call.

② Dispatch is the lowering table

_lower_inst!(ctx, inst::IRBinOp,  …) = lower_binop!(…)
_lower_inst!(ctx, inst::IRICmp,   …) = lower_icmp!(…)
_lower_inst!(ctx, inst::IRSelect, …) = lower_select!(…)
_lower_inst!(ctx, inst::IRPhi,    …) = lower_phi!(…)
# … 13 instruction types, 13 methods …
_lower_inst!(ctx, inst::IRInst, …) =

No switch. No visitor. Adding an instruction = adding a method — from any package. The catch-all's only job is to be loud.

The theorem is a for-loop

append!(all_gates, lr.gates)             # compute
_emit_copy_gates!(all_gates,             # copy the answer out
                  lr.output_wires, copy_wires)
for i in length(lr.gates):-1:1           # uncompute
    push!(all_gates, lr.gates[i])
end

Every gate is its own inverse — Bennett's 1973 theorem is a for-loop with a negative step.

Teleportation, zero gates

function teleport(ψ::QBool)
    b = QBool(0.5)
    c = false ⊻ b
    b ⊻= ψ
    m_phase = Bool(dual(ψ))
    m_value = Bool(b)
    m_value && not!(c)
    m_phase && not!(dual(c))
    return c
end
← fair quantum coin
← Bell pair
← conjugate-basis readout — CONSUMES ψ
← ordinary conditionals — one in the dual view
“If your program reads like a circuit diagram, it is wrong.”
⊻= mutates — against Julia precedent (#249, #3217) and correct here: no-cloning means no caller could expect a value.

The loop closes: oracle(f, x)

function deutsch_jozsa(f, ::Val{N}) where {N}
    x = QInt{N}(0); superpose!(x)
    b = minus()
    b ⊻= oracle(f, x)          # ordinary Julia f, compiled by Bennett
    return Int(dual(x)) == 0   # one query
end
oracle(f, x) crosses a weakdep extension — the only file in Sturm that names a Bennett type; using Sturm never pays LLVM’s precompile. Both package seams are the same trick: a Ref{Any}(nothing) filled by the downstream package’s __init__.

Two lessons

The marginals lied
Our first teleport moved the value and dropped the phase. Its test passed — output statistics looked fine. The fixed one reads 1024/1024 on a probe where the broken one reads ≈512.
Test the whole channel, not what leaks out of it.
Error correction is a function
Protect(enc)(physical_iid(enc, bit_flip(p)))
# channel in → channel out
pinned two-sided: helps below p = ½, hurts above — a sign-flipped decoder passes any one-sided test.

The zinger

Q&A: the space–time dial

Knill 1995, Theorem 2.1 — the reversible pebble game on n steps with s pebbles:
F(1, s) = 1                        for s ≥ 1
F(n, 1) = ∞                        for n ≥ 2
F(n, s) = min over m of  F(m, s) + F(m, s−1) + F(n−m, s−1)
F(n, s) finite ⟺ n ≤ 2(s−1)
Six pluggable BennettStrategy subtypes — adding a seventh is adding a method:
DefaultStrategy — forward + CNOT-copy + reverse
CheckpointStrategy — per-group checkpoint-and-free
EagerStrategy — gate-level dead-end cleanup
PebbledStrategy(max_pebbles) — Knill, gate-level
ValueEagerStrategy — PRS15 Alg. 2, Kahn reverse
PebbledGroupStrategy(max_pebbles) — group-level, wire reuse

Q&A: the three-layer history tape

L1
injective
the step is a bijection on machine state — reversal recomputes it. Nothing is logged.
0 bytes
L2
min-cut delta
log the smallest set of overwritten words that makes the step invertible. Enzyme’s idea.
O(cut)
L3
checkpoint + replay
snapshot every K steps, replay forward from the nearest checkpoint. rr’s idea.
O(state)/K
unrun!(rs, vm) drains all three layers: rs.current == rs.initial and isempty(rs.history).
