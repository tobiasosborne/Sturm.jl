Julia is uniquely placed to be a quantum programming language — I won't argue it abstractly. Watch for six levers.

① The compiler is a library

ir_string = sprint(io -> code_llvm(io, f, arg_types;
                       debuginfo = :none, optimize, dump_module = true))
mod = parse(LLVM.Module, ir_string)

A runtime function value in — the compiler's IR out. In-process. While f is still callable.

C++: write a clang plugin. Python: there is no IR. Julia: two lines, and it works for anything that reaches LLVM.

Julia 1.12 outlines slow paths — some closures have no .instance to compile. Fix: rebuild InteractiveUtils._dump_function from Base._which + specialize_method + typeinf_code. The reflection stack is just more Julia you can call.

② Dispatch is the lowering table

_lower_inst!(ctx, inst::IRBinOp,  …) = lower_binop!(…)
_lower_inst!(ctx, inst::IRICmp,   …) = lower_icmp!(…)
_lower_inst!(ctx, inst::IRSelect, …) = lower_select!(…)
_lower_inst!(ctx, inst::IRPhi,    …) = lower_phi!(…)
# … 13 instruction types, 13 methods …
_lower_inst!(ctx, inst::IRInst, …) =
    error("no lowering for $(typeof(inst))")

No switch. No visitor. Adding an instruction = adding a method — from any package. The catch-all's only job is to be loud.

③ The entire simulator

@inline apply!(b, g::NOTGate)     = (b[g.target] ⊻= true;                          nothing)
@inline apply!(b, g::CNOTGate)    = (b[g.target] ⊻= b[g.control];                  nothing)
@inline apply!(b, g::ToffoliGate) = (b[g.target] ⊻= b[g.control1] & b[g.control2]; nothing)

This is not an excerpt. This is the simulator.

union-splitting on three concrete gate types — a 28k-gate circuit simulates with <200 KiB allocated.

The theorem is a for-loop

append!(all_gates, lr.gates)             # compute
_emit_copy_gates!(all_gates,             # copy the answer out
                  lr.output_wires, copy_wires)
for i in length(lr.gates):-1:1           # uncompute
    push!(all_gates, lr.gates[i])
end

Every gate is its own inverse — Bennett's 1973 theorem is a for-loop with a negative step.

julia> gs[14:23] == reverse(gs[1:10])
true

— and it's a doctest: CI fails if the theorem does.

What arithmetic costs

QCLA 32-bit multiply — Toffoli-depth 56 vs 180 schoolbook · QROM T-count exactly 4(L−1), width-independent (matches Babbush–Gidney) · shadow-memory store 24 CNOT vs a 7,122-gate MUX

SHA-256 round: 1,632 Toffoli vs hand-optimized 683 — ~2.4× worse. It's in our own benchmark table.
