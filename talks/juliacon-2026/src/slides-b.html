function teleport(ψ::QBool)
    b = QBool(0.5)
    c = false ⊻ b
    b ⊻= ψ
    m_phase = Bool(dual(ψ))
    m_value = Bool(b)
    m_value && not!(c)
    m_phase && not!(dual(c))
    return c
end

Knill 1995, Theorem 2.1 — the reversible pebble game on n steps with s pebbles:
F(1, s) = 1                        for s ≥ 1
F(n, 1) = ∞                        for n ≥ 2
F(n, s) = min over m of  F(m, s) + F(m, s−1) + F(n−m, s−1)
F(n, s) finite ⟺ n ≤ 2(s−1)

Q&A: the three-layer history tape

L1
injective
the step is a bijection on machine state — reversal recomputes it. Nothing is logged.
0 bytes
L2
min-cut delta
log the smallest set of overwritten words that makes the step invertible. Enzyme’s idea.
O(cut)
L3
checkpoint + replay
snapshot every K steps, replay forward from the nearest checkpoint. rr’s idea.
O(state)/K
unrun!(rs, vm) drains all three layers: rs.current == rs.initial and isempty(rs.history).
